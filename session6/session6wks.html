    Hands-on.

    • Definition of Monotonic: A sequence \(a_n\) is called increasing if \(a_n \lt a_{n+1}\) for all \(n \geq 1\text{,}\) that is \(a_1 \lt a_2 \lt a_3 \lt \cdots\text{.}\) It is called decreasing if \(a_n \gt a_{n+1}\) for all \(n \geq 1\text{.}\) It is called monotonic if it is either increasing or decreasing.
      🔗
      🔗
    • Definition Bounded Sequence: A sequence \(a_n\) is bounded above if there is a number \(M\) such that \(a_n \leq M\) for all \(n \geq 1\text{.}\) It is bounded below if there is a number \(m\) such that \(m \leq a_n\) for all \(n \geq 1\text{.}\) If it is bounded above and below, then \(a_n\) is a bounded sequence.
      🔗
      🔗
    • Monotonic Sequence Theorem: Every bounded monotonic sequence is convergent.
      🔗
      🔗
    • Squeeze Theorem for Sequences: If \(a_n \leq b_n \leq c_n\) for \(n \geq n_0\) and \(\lim_{n\to\infty} a_n = \lim_{n\to\infty} c_n = L\text{,}\) then \(\lim_{n\to\infty} b_n = L\text{.}\)
      🔗
      🔗
